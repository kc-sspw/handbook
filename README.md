## Dwie kategorie pracy

W organizacji `kc-sspw` rozróżniamy:

1. **projekty Komisji** — rozwiązania, które mają być wdrażane, utrzymywane i przejmowane przez kolejne osoby;
2. **repozytoria szkoleniowe** — kod tworzony przede wszystkim po to, żeby się uczyć, ćwiczyć i eksperymentować.

Te dwa typy repozytoriów nie powinny mieć identycznego poziomu formalności. Szczegóły znajdują się w odpowiednich dokumentach.
